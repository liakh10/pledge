# _template-protocol — скелет для протокольного концепта

Копировать целиком в `robinhood/<name>/`, не редактировать на месте.
Мем-концепты собираются НЕ отсюда, а от `whorefly/index.html` (см. два трека в `../CLAUDE.md`).

## Что уже лежит внутри
```
lib/wallet.js      EIP-6963 подключение кошелька, Robinhood Chain
lib/chains.js      цепь и публичные RPC — уходит в браузер, приватных ключей и токенов здесь быть не может
lib/server.js      серверное чтение цепи, приватный RPC берётся из process.env.ROBINHOOD_RPC
lib/store.js       Upstash Redis, с памятью для локального дев-сервера
lib/http.js        json / ipOf / body
lib/siteconfig.js  серверное чтение config.js (адреса контрактов без передеплоя)
contracts/         solc 0.8.28 + экспорт ABI; src/ и test/ пустые
dev.mjs            локальный сервер: статика + функции из api/
vercel.json        cleanUrls, кэш, maxDuration для api/tick
```
Переименовать префиксы (`STIPS_`, `st:`) под новый проект: `grep -rn "STIPS_\|'st:" lib api`.

## Порядок работы
1. **Референс.** Открыть сайт-образец, снять с него цифрами: фон, шрифты, размер и вес h1, радиус и фон
   карточек, цвет рамки, ширину сайдбара. Записать в `NOTES.md` проекта. Без этого шага получится
   «в своей вселенной», а это для протокола уже отклонялось.
2. **Механика и контракты.** Написать `contracts/src/*.sol`, скомпилировать, экспортировать ABI.
3. **Форк-тест обязателен.** `contracts/test.mjs` на реальном состоянии mainnet (ethereumjs VM +
   RPCStateManager). Деплоить можно только при зелёном прогоне. Один прогон ≈ 280 RPC-запросов,
   поэтому тесты гонять на **публичном** RPC, приватный беречь для продакшена.
4. **Сайт.** Продуктовая анатомия: шапка → hero с метриками → живые списки → как работает → фишка-инструмент
   → proof с адресами → футер с дисклеймером. Текст сухой, пустые состояния честные.
5. **Фишка.** Инструмент, который считает или показывает настоящее. Проверка: что посетитель делает здесь
   такого, чего не сделает в эксплорере.
6. **docs.html** обязателен.
7. **Мобилка.** 375 px, `scrollWidth === clientWidth`. Проверять числом, а не на глаз.
8. **Деплой.** Свой репозиторий `liakh10/<name>`, свой Vercel-проект, `CA = "SOON"`.
9. **REGISTRY.md** — строка о проекте сразу после деплоя.
10. **X-пак.** Аватар 1000×1000 и баннер 1500×500, левый нижний угол 240×230 пустой.

## Секреты
- Приватный RPC **только** в `.env.local` (локально) и в переменных Vercel. В `lib/chains.js` он не попадает
  никогда: этот файл уходит в браузер, а репозитории публичные.
- Ключи оракула и кипера — только в переменных Vercel, в коде их нет.
- `.env.local` должен быть в `.gitignore` до первого коммита.
